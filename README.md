# 💰 FinAssist — Financial Assistant

A zero-dependency personal finance tracker for home income and expenses — no accounts, no
backend, no build step. Your data stays in your browser.

**Live demo:** https://ahmedsh505.github.io/financial-assistant/

## Features

- 📊 **Dashboard** — monthly totals, balance, and Chart.js visualizations (income vs. expenses, spending by category).
- 💵 **Income & expense tracking** — add entries with amount, category, date, and notes.
- 📅 **Month navigation** — flip between months/years; every view filters to the selected month.
- 💾 **Private by design** — everything persists to `localStorage`; nothing ever leaves your machine.
- 🚀 **Zero install** — one HTML file, one stylesheet, one script.

## Run locally

Open `index.html` in any browser. That's it.

## Stack

Vanilla JavaScript · Chart.js (CDN) · CSS custom properties · `localStorage`
